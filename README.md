# Encuesta de Satisfacción con Streamlit y Supabase

Aplicación en Streamlit para recoger encuestas de satisfacción y almacenar las respuestas de forma numérica en Supabase.

## Funcionalidades
- Respuestas en texto para el usuario
- Almacenamiento numérico (1–5) en Supabase
- Configuración segura con variables de entorno
- Lista para producción y despliegue

## Instalación

```bash
git clone https://github.com/tu-usuario/streamlit-encuesta-satisfaccion.git
cd streamlit-encuesta-satisfaccion
pip install -r requirements.txt
